This is a Automatic Navigating robot made with simple components capable of detecting obstacles in its path,
scanning for a clear path, and changing it's path accordingly.

//components Used: L298N Motor Driver, 2 BO Motor 5V, 2 BO wheels(65mm), 1 Free wheel,
Tower pro micro servo , Nodemcu ESP8266 V1, HC-SR04 Ultra sonic distance sensor//
